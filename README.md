# Elling & Sons (ellingandsons.com)

Static site for Elling & Sons, hosted on GitHub Pages.

## Stack
- Plain HTML, CSS, JavaScript
- Hosted via GitHub Pages
- Fonts via Adobe Fonts (Typekit)
- Favicons included (already generated)
